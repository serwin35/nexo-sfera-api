UWAGA! Biblioteka powstała w wyniku kompilacji tego projektu nie jest możliwa do użycia w programach InsERT nexo.

Przykłady z tego projektu prezentują sposób pisania skryptów w słowniku "Definicje pól JPK" w nexo.
Po wykonaniu operacji "Edytuj kod" (Ctrl+K) na wybranym elemencie definicji pól kod z wybranej funkcji należy wkleić do edytora kodu.
Następnie należy aktywować (kolumna "Aktywny") wybrany element.
W kreatorze generowania zbioru plików kontroli skarbowej należy zaznaczyć parametr "Użyj wyrażeń użytkownika" aby kod własnej funkcji był uwzględniony podczas generowania.
