InsERT to moduł przeznaczony do integracji Sello NX i serwisu PrestaShop.

Aby zainstalować moduł, należy:
    1. Utworzyć kopię bazy danych na wypadek niepowodzeń lub błędów.
    2. Spakować cały folder "insertmodule" do ZIP.
    3. W panelu administratora PrestaShop wybrać zakładkę "Moduły" → "Menedżer modułów".
    4. Kliknąć przycisk "Załaduj moduł" i wybrać spakowany folder z punktu nr 2.
