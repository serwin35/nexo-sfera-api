Przykłady rozszerzeń dla InsERT nexo.

Proszę korzystać i dowolnie modyfikować, po wykonaniu następujących kroków:

 1. Zmienić dane dostawcy rozszerzeń na swoje własne.
 2. Zmodyfikować informacje w AssemblyInfo.cs
 3. Wygenerować nowe GUID-y funkcji, żeby się przez przypadek nie powieliły.

Zawiera implementację następujących rodzajów rozszerzeń:

 1. IFunkcjaWyliczaniaCenyBazowej
	a. FunkcjaWyliczaniaCenyZPliku - pobiera cenę towaru z pliku CSV
	b. FunkcjaWyliczaniaCenyBazowejNa5 - określa cenę na stałą kwotę: 5,00

 2. IFunkcjaWyrownywaniaCeny
 	a. FunkcjaWyrownywaniaCenyDo99 - proste zaokrąglanie cen do ,99. 

	Wymaga wdrożenia za pomocą własnego kodu, bo w UI nie da się ustawić i wywołać tej funkcji w cenniku.
	Przykład takiego kodu:

    public void PodlaczenieFunkcjiDoCennikaSpecjalnego()
    {
        using (Uchwyt sfera = UruchomSfere())
        {
            ICenniki cenniki = sfera.PodajObiektTypu<ICenniki>();
            Cennik cennikSpecjalny = cenniki.Dane.Wszystkie().Where(c => c.Tytul == "Specjalny").FirstOrDefault();
            Assert.IsNotNull(cennikSpecjalny);
            if (cennikSpecjalny != null)
            {
                using (ICennik cennikSpecjalnyBO = cenniki.Znajdz(cennikSpecjalny))
                {
                    cennikSpecjalnyBO.Dane.DomyslnaFunkcjaWyrownywaniaCen = FunkcjaWyrownywaniaCenyDo99.Guid;
                    foreach (var poz in cennikSpecjalnyBO.Pozycje.Wszystkie)
                    {
                        var oPoz = poz.RozpocznijEdycje();
                        oPoz.Dane.FunkcjaWyrownywaniaCeny = cennikSpecjalnyBO.Dane.DomyslnaFunkcjaWyrownywaniaCen;
                        oPoz.WyrownajCeny();
                        Assert.IsTrue(poz.ZakonczEdycje());
                    }
                    Assert.IsTrue(cennikSpecjalnyBO.Zapisz());
                }
            }
        }
    }

 3. IFunkcjaPobieraniaDanychDlaWydruku - pozwala na dostarczenie dodatkowych danych w kontekście wydruku określonego obiektu.	
	Aby z niej skorzystać, wystarczy ją pobrać za pomocą metody PobierzFunkcje, która znajduje się we wzorcu (zakładka Code)
	podając odpowiedni identyfikator lub nazwę, a następnie wywołując metodę PodajDane.
	a. FunkcjaPobieraniaDanychDlaWydruku - dostarcza nazwę lub nazwę skróconą, jeśli przekaże się do niej dane asortymentu lub podmiotu
		za pomocą encji lub opisowo.
		Przykład wyrażenia 1: {PobierzFunkcje(Guid.Parse("748E2729-3397-4AE8-911B-B735FD7BF23A")).Pobierz(Dokument.encjaDokumentu.Podmiot.Current)}
		Przykład wyrażenia 2: {PobierzFunkcje("Przykładowa funkcja pobierania dodatkowych danych na wydruku.").Pobierz("Podmiot:" + Dokument.encjaDokumentu.Podmiot.Id.ToString())}

 4. IDodatkowyObiektDlaWydruku - pozwala na dodanie własnych danych, dowolnego typu, do wskazanego typu wzorca wydruku
	a. DodatkowyObiektDlaWydruku - udostępnia kolekcję obrazków pudełek programów nexo PRO pobranych ze strony WWW Insertu.
		Dodatkowe dane są widoczne w edytorze wzorca wydruku faktury sprzedaży na zakładce Dictionary jako "MojeObrazki".
