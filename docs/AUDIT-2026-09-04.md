# Audit 2026-09-04 - SDK 61.1.0.9431 alignment, coverage and gap analysis

## 1. What was wrong (root causes, verified against SDK metadata)

`DynamicPropertyHelper` swallows missing properties and returns `0`/`null`, so wrong SDK property names never threw -
they silently produced wrong data. Names extracted from `InsERT.Moria.ModelDanych.dll` (see `SDK-ENTITY-REFERENCE.md`)
showed that the following were read for years although they do not exist:

| Area | Wrong name(s) | Real SDK member | Effect before the fix |
|---|---|---|---|
| Document totals | `WartoscNetto`, `WartoscBrutto`, `WartoscVat` | `Wartosc.NettoPoRabacie/BruttoPoRabacie/VatPoRabacie` | totals = 0 in list/detail |
| Due date | `Dokument.TerminPlatnosci` | `PlatnosciDokumentow[].Termin`, `Rozrachunek.TerminPlatnosci` | `dueDate` always null, `isOverdue` never true |
| Sale/issue dates | `DataWystawienia` (alone), `DataSprzedazy` on non-commercial docs | `DataWydaniaWystawienia`, `DokumentHandlowy.DataSprzedazy` | null dates on FS/FZ/ZK mappers |
| Line unit | `Jednostka`, `JednostkaMiary` | `JednostkaMiaryAs.JednostkaMiary.Symbol`, `IloscWJednostceBazowej` | every line reported "szt." |
| Warehouse line product | `Asortyment` | `AsortymentAktualny` | `productId`/`productSymbol` null on WZ/PZ/RW/PW/MM lines |
| Settlements | `KwotaDoRozliczenia`, `DataPlatnosci`, `DataWystawienia` | `KwotaPozostala`, `TerminPlatnosci`, `DataPowstania` | paid/overdue filters and days-overdue wrong |
| ZPM | `DataDokumentu`, `PozycjaKomplet.Asortyment`, `PozycjeSkladniki.Dodaj(asortyment)` | `DataWprowadzenia`, `AsortymentAktualny`, `Dodaj(id, qty)` | date filters dropped everything; component add threw |
| Photo gallery | `Dane.Wszystkie()` on `IGaleriaZdjec`, `NazwaPliku`... | `WszystkieZdjecia()`, `Nazwa`, `RozmiarBajty` | GET returned empty |
| Units on create | `item.Unit` ignored (default "szt.") | `Pozycje.Dodaj(asortyment, qty, JednostkaMiaryAsortymentu)` | quantity posted in base unit regardless of request |

All of the above are fixed in this change set (see CHANGELOG 2026-09-04). **Runtime verification on a Windows box with a live
Nexo database is still required** - nothing here could be compiled or executed on macOS.
